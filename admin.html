Compartir tu página

Para que tus clientas puedan ver tu página necesitas subirla a internet. La forma más fácil y gratis es usando GitHub Pages. Sigue estos pasos:

  1. Ve a github.com y crea una cuenta gratis.
  2. Crea un repositorio nuevo llamado kydreamsgt.
  3. Sube los archivos index.html y admin.html.
  4. Ve a Settings → Pages y activa GitHub Pages.
  5. ¡Listo! Tu link será: tunombre.github.io/kydreamsgt

También puedes usar Netlify (netlify.com) — solo arrastra tus archivos y te da un link al instante.
